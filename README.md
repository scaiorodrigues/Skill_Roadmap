# Skill RoadMap — GPS de carreira (FromTech)

Importe seu perfil do LinkedIn, descubra os 5 caminhos de carreira mais rentáveis para o seu
perfil, escolha um e siga um roadmap completo com skills, cursos e certificações.

- Visão do produto: [`docs/product-vision.md`](docs/product-vision.md)
- Schema do banco: [`docs/database-schema.md`](docs/database-schema.md)
- Tracking de progresso: [`docs/track-spec.md`](docs/track-spec.md)
- Plano de implementação: [`docs/roadmap.md`](docs/roadmap.md)

## Privacidade

Sem login e sem conta. O histórico de pesquisas fica só no navegador do usuário. Para gerar a análise, o texto do perfil é enviado ao
Google Gemini por um intermediário que não o armazena.

## Rodando localmente

```bash
cp .env.example .env.local   # preencha as variáveis
npm install
npm run dev
```

Setup do Supabase e do login: [`supabase/README.md`](supabase/README.md) e [`docs/auth-setup.md`](docs/auth-setup.md).

## Stack

Next.js 14 (App Router) · TypeScript · Tailwind · Supabase · Gemini Flash · Vercel
